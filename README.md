# Atelier Brown

Static site, no build step. Open index.html, or deploy the folder as is.

Deploy free: Netlify Drop (drag this folder to app.netlify.com/drop), Cloudflare Pages, or GitHub Pages. Add a custom domain in the host's settings.

Pages: index (landing), advisor (3D), fabrics, planner, about. Shared data and logic: assets/data.js. Shared styles: assets/style.css.
